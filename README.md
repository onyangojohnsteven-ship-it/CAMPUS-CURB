# 🎓 Campus Curb Marketplace

**Campus Curb** is a high-performance, mobile-first Progressive Web App (PWA) designed exclusively for university students to buy and sell IT materials safely within their campus community.

![Campus Curb Logo](../campus_curb_logo_1778481383344.png)

## 🚀 Features

- **PWA Ready**: Installable on Android, iOS, and Desktop for a native app-like experience.
- **Dark Mode Support**: Seamless toggle between Light and Dark themes with system preference detection.
- **Campus Verified**: Design philosophy centered around student trust and local meetups.
- **Category Filtering**: Browse specific IT gear including Laptops, Engineering Kits, Networking, and more.
- **Integrated Shopping Cart**: Real-time cart management with a sleek slide-out drawer.
- **Detailed Listings**: View full item specs, condition badges, and seller campus locations.
- **Offline Access**: Service Worker integration for reliable performance even with spotty campus Wi-Fi.

## 🛠️ Tech Stack

- **Frontend**: Semantic HTML5, Vanilla CSS3 (Flexbox/Grid).
- **Interactivity**: Pure JavaScript (ES6+) — No heavy frameworks for maximum performance.
- **Icons**: Font Awesome 6.4.
- **Typography**: Montserrat & Inter via Google Fonts.

## 📦 Installation

To run this project locally:

1. Clone the repository:
   ```bash
   git clone https://github.com/onyangojohnsteven-ship-it/CAMPUS-CURB.git
   ```
2. Navigate to the project folder:
   ```bash
   cd CAMPUS-CURB
   ```
3. Open `html/index.html` in your browser (or use a local Live Server for PWA features).
